yurumeet

LINE のようにトーク中心で使える self-hosted messaging app。中央のサービスに預けず、自分のサーバーに置いて動かす。 DM・グループ・タイムライン・Story がひとつの画面にまとまる。

AGPL-3.0-only · github.com/tako0614/yurumeet · ActivityPub (yurucommu 互換 API) · Cloudflare Workers

Cloudflare にデプロイ 導入手順 GitHub

画面

ホーム・トーク・タイムライン・通知。画面のはじに並ぶレールが そのまま目次で、未読はタブのバッジで届く。

ホーム

友だちとグループがひとつのリストに並ぶ。ノートに「いまの一言」を残せて、QRコードでその場で友だちを追加できる。

トーク

DM もコミュニティチャットも同じルームリストに並ぶ中心画面。リクエストとアーカイブで、受け取る会話を自分で選べる。

タイムライン

フォローしている人の投稿と Story の公開の場。「いまどうしてる?」からそのまま投稿できる。

通知

フォロー・いいね・返信・メンション・リポストを種類で絞り込める。フォローリクエストはその場で承認・拒否できる。

QRコードで友だちを追加

自分のコードを見せるか、相手のをスキャンするか。yurucommu と同じ形式なので、アプリやサーバーが違っても追加できる。

モバイル

同じサーバーに接続して、トーク・タイムライン・Story を片手で扱える。

自分のサーバーで動かす

  • アカウントもトークのデータも、自分のサーバーに残る
  • ActivityPub で動き、yurucommu 互換のアカウント / API を使う。ほかのサーバーともつながる
  • AGPL-3.0 のオープンソース。コードを確認して必要なら変えられる
  • yurume は client id / 短縮名

導入

中央でホストされるアプリではない。Cloudflare に自分でデプロイして使う。

現在利用できるのは Cloudflare へのセルフホスト。Takosumi 導入は検証中で、固定リリースからの作成・認証・キュー・定期実行・migration・公開 URL・rollback・destroy を確認できるまで公開導線は有効化しない。このサイトは紹介ページで、実際に動く yurumeet は自分でデプロイした実行環境のほう。

自分の環境を管理

root OpenTofu module を使い、credential・承認・migration・recovery を自分の operator authority で管理する。 

$ git clone https://github.com/tako0614/yurumeet.git
$ cd yurumeet
$ bun install
$ bun run check
# then follow your operator-owned self-host runbook
